竹仁畢業歌創作集：放上網路並嵌入 Rpage 的步驟
==============================================

這個資料夾就是完整網站：
  index.html   網頁本體（含歌詞、封面、姓名）
  audio\       184 首歌（每首約 1.2 MB，共約 220 MB）
兩者要放在一起，資料夾結構不能改。

------------------------------------------------
方法 A：放到 GitHub Pages（免費，約 15 分鐘）
------------------------------------------------
1. 到 https://github.com 註冊並登入（建議用學校或班級的帳號）。
2. 右上角「+」→「New repository」
   - Repository name：例如 zhuren-songs（只能用英文、數字、-）
   - 選「Public」（GitHub Pages 免費版必須是公開）
   - 按「Create repository」
3. 在新建立的頁面點「uploading an existing file」。
   - 先把 index.html 拖進去，按下方綠色「Commit changes」。
   - 再按「Add file」→「Upload files」，把整個 audio 資料夾拖進去。
     網頁一次最多 100 個檔案，所以 audio 要分兩次上傳：
     第一次選 601～604 開頭的檔案，第二次選 605～607 開頭的檔案。
     （拖整個 audio 資料夾時，GitHub 會自動保留 audio/ 這層資料夾。
      若是直接選檔案，請先在上傳頁的路徑欄輸入 audio/ 再拖檔。）
4. 到該 repository 的「Settings」→ 左側「Pages」
   - Source 選「Deploy from a branch」
   - Branch 選「main」、資料夾選「/ (root)」，按「Save」
5. 等 1～3 分鐘，頁面上方會出現網址，格式像：
   https://你的帳號.github.io/zhuren-songs/
   打開確認能播放、能看歌詞。

------------------------------------------------
方法 B：放到學校主機
------------------------------------------------
把整個資料夾交給資訊組，請他們放到學校網頁主機任一個可公開瀏覽的位置，
並告訴你網址（例如 https://www.學校網域/songs/）。
注意：主機需要允許 .webm 檔案（MIME 類型 audio/webm 或 video/webm）。

------------------------------------------------
嵌入 Rpage 2.0
------------------------------------------------
1. 登入 Rpage 後台 →「模組管理」→「自訂模組」→「新增」
2. 模組標題：我們的畢業歌創作集
3. 切換到「HTML 編輯 / 原始碼」模式，貼上下面這段
   （把網址換成你在上面得到的網址）：

<iframe src="https://你的帳號.github.io/zhuren-songs/" title="我們的畢業歌創作集" style="width:100%; height:900px; border:0;" allow="autoplay; fullscreen" loading="lazy"></iframe>
<p style="text-align:center"><a href="https://你的帳號.github.io/zhuren-songs/" target="_blank" rel="noopener">在新視窗開啟完整版</a></p>

4. 儲存後，到「頁面管理」→「首頁畫面設定」（或要放的內頁的「頁面設定」），
   把這個自訂模組加到想放的位置，建議放在「一欄式」或滿版區塊，比較寬。
5. 儲存，回前台檢查。

小提醒：
- 高度 900px 可以自行調整，例如 700px 或 1200px。網頁在框內可以自己捲動。
- 如果儲存後 iframe 被刪掉或前台一片空白，代表學校的 Rpage 不允許 iframe，
  請資訊組開放，或改用「連結模組」放按鈕連到同一個網址。
- 網頁顯示學生全名，公開前請確認符合學校規定。
- 之後要改歌或歌詞，改好的 index.html 或 audio 檔重新上傳到同一個位置即可，
  Rpage 不用動。
